# APG Vastu Chakra — cinematic concept page

A concept home page for a Vastu learning platform: the 16-zone Vastu chakra built as an instrument in ivory, lacquer and brass, exploded into eight pieces that assemble as you scroll, then run.

- Single `index.html`, no build step. Three.js r128 and its post-processing passes load from jsDelivr; fonts from Google Fonts.
- Chapters: the instrument, trace the outline, the centre, the main door, lock North, sixteen zones, devta, zone balance, share, the academy, close.
- Scroll drives a spring-settled camera, part assembly, a day-to-night palette shift with letterbox, a travelling key light, hover readings on each zone, and an optional synthesised score (the Sound control in the nav).
- Phones drop depth of field and shadows resolution; quality steps down automatically if frames run long.

Zone areas, the plan and the 253° door reading are sample data. Zone colours and the devta layout are indicative.

Live: https://abhi-hyperscripts.github.io/vastu-chakra-cinematic/
